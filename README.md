**Tarikh-ul-Islam** is an interactive, source-referenced platform for exploring Islamic history from the earliest prophets and the first generations of humanity through the life of Prophet Muhammad ﷺ, the Khulafa, Islamic civilizations, scholars, scientists, empires, and the modern era.

The project is built around the idea that Islamic history should not be viewed simply as a story of the last 1,400 years. It encompasses the history of faith, revelation, prophets, humanity, Muslim communities, civilizations, scholarship, and historical events across the ages.

> **From the earliest prophets to the modern world — explore, learn, and discover Islamic history.**

## 🕊️ The Scope of Islamic History

Tarikh-ul-Islam is intended to explore Islamic history across a much broader period than the commonly referenced 1,400+ years of Muslim civilization.

The platform will progressively explore topics connected with:

### 🌌 Creation and the Beginning

Where supported by reliable Islamic sources, the project may explore:

- Allah's creation
- Creation of the heavens and earth
- Angels
- Adam عليه السلام

These subjects will be presented according to the Qur'an and reliable Islamic sources, while clearly distinguishing established evidence from reports whose authenticity or interpretation is disputed.

## 📚 Historical Sources & Accuracy

Tarikh-ul-Islam aims to present historical information responsibly and transparently.

Where appropriate, information may be identified according to its source or level of evidence, including:

- **Qur'an**
- **Authentic Hadith**
- **Classical historical reports**
- **Primary historical sources**
- **Secondary scholarship**
- **Scholarly interpretations**
- **Disputed or weak narrations**

The goal is not simply to collect popular historical stories, but to help users understand **where information comes from and how reliable or disputed it may be**.

When historical or scholarly disagreements exist, the project aims to acknowledge them rather than presenting one interpretation as unquestionable fact.

## 🛠️ Technology

| Layer | Technology |
|---|---|
| Framework | [TanStack Start](https://tanstack.com/start) and [TanStack Router](https://tanstack.com/router) |
| UI | React 19, TypeScript |
| Build tool | Vite |
| Styling | Tailwind CSS 4, Radix UI primitives (shadcn/ui style components) |
| Data fetching | TanStack Query |
| Forms and validation | React Hook Form, Zod |
| Animation | Framer Motion |
| Icons | Lucide |
| Hosting | Cloudflare Workers |
| Version control | Git and GitHub |

**Planned backend:** Python (FastAPI), PostgreSQL, SQLAlchemy, Alembic, Pydantic and pytest, for a database-driven content system, admin dashboard, search and quizzes. The existing frontend will stay in place, and data will be moved to the API step by step.

Additional technologies may be introduced as interactive maps, animations, AI features, and other systems are developed.

## ▶️ Run Locally

### Prerequisites

- [Node.js](https://nodejs.org/) (current LTS version recommended)
- npm (comes with Node.js)
- [Git](https://git-scm.com/)

### Setup

```bash
# 1. Clone the repository
git clone https://github.com/junaidahmadsiddiqui/tarikh-islam.git
cd tarikh-islam

# 2. Install dependencies
npm install

# 3. Start the development server
npm run dev
```

Then open the local URL printed in your terminal.

### Available scripts

| Command | What it does |
|---|---|
| `npm run dev` | Starts the development server |
| `npm run build` | Creates a production build |
| `npm run build:dev` | Creates a build in development mode |
| `npm run preview` | Previews the production build locally |
| `npm run lint` | Runs ESLint |
| `npm run format` | Formats the code with Prettier |

> The repository also contains a `bun.lock` file. npm is the documented way to run the project.

### Project structure

```
.
├── public/             # Static assets
├── src/                # Application source (routes, components, content)
├── components.json     # UI component configuration
├── vite.config.ts      # Vite configuration
├── tsconfig.json
├── package.json
└── AGENTS.md
```
