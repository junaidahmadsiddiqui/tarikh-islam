# Tarikh e Islam

Islamic History website built with React, TypeScript and Vite. Explore 1400 Years
of Islamic History
Journey through the Seerah of the Prophet ﷺ, the Rightly-Guided Caliphs, the great empires, scholars, and scientists — all rendered as beautifully interactive stories, timelines, and maps.An interactive, source-referenced platform for learning the complete history of Islam — from Arabia before the Prophet ﷺ to the modern era.

Tarikh-ul-Islam. Built for the ummah, with references.

## Run

npm install
npm run dev
